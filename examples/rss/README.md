# RSS Reader UI Demo

Paginated news-card display using eight bundled sample headlines.

## Usage

Two headlines appear at a time, with sources and timestamps. Pages advance every five seconds; the hardware button advances immediately.

## Behavior and Limits

This example is an offline layout demo. It does not fetch or parse XML feeds. Edit the comma-separated headline/source/time lists together and update `totalPages` to match the number of pairs.

See [Elk app development](../../docs/ELK_APPS.md) for installation, API constraints, and tests.
