# IoT Monitor Demo

Six-card dashboard with sample temperature, humidity, motion, door, and light readings.

## Usage

Runs offline. Press the hardware button to toggle the simulated kitchen light. Other sample readings update once per second and stay within bounded ranges.

## Behavior and Limits

This example demonstrates the UI and does not subscribe to sensors or control real hardware. Use the MQTT Notifications example for a working MQTT receiver.

See [Elk app development](../../docs/ELK_APPS.md) for installation, API constraints, and tests.
